App Summary

WhiteCat Counter කියන්නේ shop business manage කරන්නෙකු සඳහා WhiteCat Team විසින් හදන ලද official web app එකක්. Items add කිරීම, sales bill හැදීම, receipt print කිරීම, stock monitor කිරීම, cashier manage කිරීම සහ account settings handle කිරීම — සියල්ල මේ app එකේ ඇතුළත් වෙනවා.

App එකේ hosting Netlify platform එකේ run වෙනවා. User data cloud database හරහා store කරනවා. Email, username, password use කරලා account create කරලා login වෙලා use කරන්නට පුළුවන්. Login වූ ගමන් cloud data page load වෙද්දීම automatic ලෙස pull කරලා load කරනවා.

නව user කෙනෙකු නම් — Login page එකේ Sign Up tab click කරලා username, email, password දීලා account create කරන්නට පුළුවන්. දැනටමත් account ඇති user කෙනෙකු නම් — Login tab use කරලා direct Counter page වෙත යන්නට පුළුවන්.

Page & Tab Details

WhiteCat Counter app එකේ main sections 5ක් තිබෙනවා. Header nav bar හරහා ඕනෑම page එකකට direct ලෙස යන්නට පුළුවන්.

Counter
Billing Page

Counter page — shop billing handle කරන main page. Item name, SKU, barcode scan / type කරලා bill table එකට add කරන්නට පුළුවන්. Quantity, unit price, serial number (has serial number ඇති items සඳහා) enter කරන්නට option දෙනවා. Bill hold කරලා තියලා, load කරලා continue කරන්නත් (Hold Bill) පුළුවන්.

Payment methods: Cash, Card, QR Pay. Discount percentage (%) හෝ fixed amount ලෙස apply කරන්නට option දෙනවා — reason field required. Tax On / Off කරන්නත්, tax rate (%) change කරන්නත් counter page හරහාම කරන්නට පුළුවන්. Customer name, phone number enter කරලා cashier select කරලා Complete Sale & Print click කළ විට bill save වෙලා receipt print window open වෙනවා.

Add Items
Inventory / Product DB

Add Items page — shop products add කරලා manage කරන page. Product name, brand, category, SKU, barcode, warranty months, cost price, selling price, stock quantity, low stock alert number set කරන්නට fields ඇත.

Categories: Computer Hardware, Peripherals, Printing & Imaging, Gaming Equipment, Networking & Security, POS Hardware, Software & ICT Services.

Allow negative stock — stock 0 ට අඩු වුනත් bill කරන්නට allow කරන option. Has serial number — sale කරද්දී serial number enter කරන option. Deleted products Recovery Bin tab එකේ 30 days ගොඩ නගා ගන්නට (restore) හෝ permanent delete කරන්නට පුළුවන්.

Sales Details
Transaction History

Sales Details page — සියලු transactions view, filter, print කරන page. Date range, payment method, invoice number, customer name, phone number use කරලා filter කරන්නට පුළුවන්.

Daily summary box: bills count, revenue, profit, items sold, discounts, average bill show වෙනවා. Each invoice View button click කළ විට full receipt detail modal open වෙනවා — serial numbers ද show වෙනවා. Print button click කළ විට receipt print window open කරනවා. Invoice Remove කළ විට recovery tab එකට move වෙනවා — permanent delete / restore options available.

Inventory Health
Stock Monitor

Inventory Health page — stock levels real-time monitor කරන page. Stock quantity ≤ low stock alert number (default 3) වූ items Warning (රතු) ලෙස mark වෙනවා. Good count, warning count, total products count header summary box එකේ show වෙනවා.

Table columns: Product, Stock, Status, Low Alert, Sell Price, Cost Price, Profit/Item. Column click කළ විට sort කරන්නට පුළුවන්. Edit Stock button click කළ විට direct stock quantity update කරන්නට prompt open වෙනවා — page reload නැතිව.

Account Manage

Account Manage page — shop identity, branding, cashier list, password, account deletion handle කරන page.

Shop & Profile: Username, owner name, shop name, address, phone, WhatsApp, other info, receipt footer message, currency, default tax rate set කරන්නට. Tax default on/off toggle, negative stock default toggle — counter page default behavior set කරනවා.

Cashier Management: Cashier name, phone, role, notes add කරලා list maintain කරන්නට. Counter page cashier select dropdown එකේ ගොඩ ගන්නට available.

Password Change: Login වෙලා ඉන්නා අතරතුරේ password change කරන්නට — minimum 6 characters.

Account Delete (Danger Zone): Account permanently delete කරන්නෙකු user data, cloud data, logo files සියල්ල delete වෙනවා. "DELETE MY ACCOUNT" phrase type කරලා password confirm කරලා checkbox tick කළ විට proceed වෙනවා. ආපසු undo කළ නොහැකි.

Data Save — Work Flow

WhiteCat Counter app හි data save workflow cloud-first architecture ලෙස design කර ඇත. Login වූ user account data Supabase cloud හි store, local device හිදීත් backup ලෙස maintain කරනවා.

◆ Data Save Steps
1
Login & Session Load
Login වෙද්දී Supabase auth session create වෙනවා. Session mode "remember me" (default) හෝ session-only ලෙස store. Login session valid නම් app page load වෙද්දීම auto login වෙනවා.
2
Profile Load
whitecat_profiles table හි user profile data pull කරනවා — username, shop name, logo URL, phone etc. Profile data app settings merge වෙලා receipt header, footer, counter title update කරනවා.
3
Cloud Data Load
whitecat_user_data table හි user data payload pull කරනවා. Payload — products, deleted products, transactions, held bills, settings, invoice sequence — සියල්ල single JSON object ලෙස per-user store. Cloud data load වූ ගමන් local backup ලෙසත් device save කරනවා.
4
Changes Save (Auto Queue)
Product save, sale complete, settings update — ඕනෑම change කළ සෑම වේලාවකදීම 180ms debounce timer ලෙස cloud push queue වෙනවා. ඒ සමගම device local storage backup (key: whitecat_user_backup_v1_{userId}) update.
5
Offline Fallback
Cloud available නොවෙද්දී device local backup use කරලා app work කරනවා. Cloud return වූ ගමන් changes sync කරනවා.
6
Logo Upload Path
Shop logo upload කළ විට whitecat_assets Supabase storage bucket හි {user_id}/logo_filename path ලෙස save. Profile table හි logo_url update. Receipt print කරද්දී logo URL ලෙස use කරනවා.

WhiteCat Counter app cloud infrastructure limits ගැන නව users දැන ගත යුතු details — data usage plan කිරීමෙදී මේ limits ගැන aware ව සිටීම important.

  • Database (500MB): Products, transactions, settings, held bills — සියල්ල per-user JSON payload ලෙස cloud database හි store. User count grow වෙද්දී limit reach වෙන්නේ නැහැ — සාමාන්ය shop use ලෙස MB ගොඩක් consume කරන්නේ නැහැ.
  • File Storage (1GB): Shop logos, assets — whitecat_assets bucket හි store. Per-upload max 1MB, PNG / JPG / WEBP only. Logo upload කිරීමේදී file size 1MB exceed නොකළ යුතු.
  • Logo Recommendation: Square logo (512×512 pixels), max 1MB, PNG format recommended. Receipt print හිදී logo proportionally scale කරනවා.
◆ Hosting (Netlify)
  • Bandwidth: Netlify free tier monthly bandwidth limit 100GB. Normal usage ලෙස limit reach වෙන්නේ නැහැ — app static files small ව ඇත.
  • Monthly Credit Update: WhiteCat team Netlify billing page monitor කර monthly update handle කරනවා. Credit balance ඉවරවීම app offline වීමට හේතු වෙනවා — monthly renewal important.
  • Current Credit: WhiteCat team සතු Netlify credits 255 — monthly deploy / update ලෙස use කරනවා. Credit ඉවරවීමට පෙර renewal plan කළ යුතු.
Monthly reminder: Netlify credit balance check කර renewal කිරීමට සැලකිලිමත් විය යුතු. Credit ඉවරවෙවී app offline ගියවිට users login කරන්නට access blocked වෙනවා. Monthly credit update = app live maintain.
