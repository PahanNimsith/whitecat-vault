Silk Economy, Tools, and Combat Expression

Silksong core loop එක combat speed + resource conversion මත heavily build වෙනවා. First game එකේ Soul bar pattern එකට වෙනස්ව මෙතැන Silk resource flow එක mobility pace එකටම tied. Hornet hits land කරන cadence එක, evade timing එක, and healing windows එකටම tactical value තියෙනවා. ඒ නිසා fight එක pure damage race එකක් නොව resource rhythm management challenge එකක් වෙනවා.

Bench-based prep loops හරහා gathering rewards combat utility වලට convert කරන්න පුළුවන්. මේ model එක quest system එකට direct connection එකක් දෙනවා, මොකද hunting/gathering contracts එකෙන් ලැබෙන rewards next region pressure meet කරන්න build strength එක හදාදෙනවා.
